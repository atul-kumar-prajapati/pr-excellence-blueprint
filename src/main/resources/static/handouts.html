5 merge now · 4 nits · 3 some risk · 2 blocking · 1 rethink / split

        
Security, data integrity or rollback red → max 2. Missing evidence → max 3. AI score is advisory.

      


      
Codex self-review prompt

      
Review the diff between this branch and main as a strict senior reviewer.

For each finding give: file, severity (blocker / major / nit), theme (intent / merge / release),
and who it would hurt.
Pay special attention to deleted lines: list any safeguard that was removed
(locks, ownership checks, idempotency keys, validation).
Then check the tests: for each test, say what behaviour it would catch if broken.
Flag tests that would pass even if the code were wrong.

Finish with a merge confidence score 1–5.
Any security, data-integrity or rollback blocker caps the score at 2.
